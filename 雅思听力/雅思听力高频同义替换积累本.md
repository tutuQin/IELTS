### 🔔 逻辑信号词速查表（答案路标词）

| 信号词 | 功能 | 动作 |
| :--- | :--- | :--- |
| *actually / in fact / but / however* | 转折→前陷阱，后答案 | 前面划掉，锁定后半句 |
| *this means that / which means / that is* | 答案即将出现 | 笔尖警觉，准备写答案 |
| *for example / such as / like / tiny bars of...* | 举例（下义词）→例子是信号，总结才是答案 | 听例子判断上位词，等并列连词 |
| *also / and / as well as / together with* | 并列→还有更多信息 | 继续听，不要提前收割 |
| *sorry / no / I mean / wait / no sorry* | 修正→前面作废 | 划掉前面，写修正后的 |
| *you know / I mean* | 同位语/解释说明→后面紧跟专有名词/地点 | 耳朵收拢，准备记主词 |
| *with... actually [doing]* | 限定修饰→打破总体粗略数字 | 过滤大时间，锁定限定动作数字 |
| *firstly / secondly / finally* | 枚举路标→换点或直接报出首个重读词 | 笔尖跟位，抓取核心重读词 |
| *more importantly / above all* | 递进强调最高级→后面紧跟核心主旨/真正原理 | 重点听取后半句主旨 (S4Q31) |
| *rather than / instead of* | 排他否定→排除后面紧跟的干扰选项 | 坚决划掉后接选项 (S2Q13) |
| *not until [year] that...* | 强调句转折→破除历史前置干扰，锁定该年份新动作 | 锁定年份后动词 (S4Q32) |
| *why don't we / how about* | 建议句型→推翻前置不合适项，敲定最终机构/地点 | 听最终附和确认词 (S3Q29) |
| *alerts us of / warns of / signals* | 生物功能警示动词→后接危险物或生理必需品 | 紧跟宾语核心名词 (S4Q39/Q40) |
