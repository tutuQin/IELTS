### 🔔 逻辑信号词速查表（答案路标词）

| 信号词 | 功能 | 动作 |
| :--- | :--- | :--- |
| *actually / in fact / but / however* | 转折→前陷阱，后答案 | 前面划掉，锁定后半句 |
| *this means that / which means / that is* | 答案即将出现 | 笔尖警觉，准备写答案 |
| *for example / such as / like* | 举例→例子是信号，总结才是答案 | 听例子判断上位词 |
| *also / and / as well as* | 并列→还有更多信息 | 继续听，不要提前收割 |
| *sorry / no / I mean / wait* | 修正→前面作废 | 划掉前面，写修正后的 |
