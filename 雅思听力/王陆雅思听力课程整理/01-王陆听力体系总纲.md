# 王陆雅思听力体系总纲

## 一、这套体系解决的不是“听力差”三个字，而是三座具体的大山

学为贵官方对语料库的概括是解决“听不懂、听不到、写不全”。把它转成可诊断的问题，就是：

1. **听不懂**：单词或表达本身不认识，缺少语义知识。
2. **听不到**：眼睛认识，但声音形式不熟；遇到英音、澳音、连读、吞音就无法识别。
3. **写不全**：已经听到答案，却在拼写、单复数、连字符、数字格式上丢分。

课程的基本顺序因此是：

> 听音词汇与拼写 → 填空题 → 选择与配对 → 地图题 → 整套模考

这也是为什么课程前半段花大量时间处理名词、形容词、复数、数字和词形，而不是一开始就讲复杂技巧。

## 二、807、语料库和真题分别做什么

### 1. 807：高频答案词的早期体系

“807”最初指从雅思听力题库中整理出的约 807 个高频填空答案词，后来成为一套高频听力词汇训练的名称。它强调的不是泛泛扩大词汇量，而是掌握考试中高概率需要写出来的词。

学习目标：

- 看见会认；
- 听见会反应；
- 不看文本会拼；
- 知道常见搭配和单复数；
- 能适应不止一种口音。

### 2. 语料库：把词汇变成声音反射

官方介绍显示，语料库包含 9 类真题语料、9 种教学与训练方法以及约 3000 个答案听写训练。不同版次覆盖的剑桥真题范围不同，但核心章节结构稳定。

语料库不是一本“背中文意思的单词书”。正确用途是建立以下链条：

```text
声音 → 词形 → 含义／场景 → 正确书写
```

### 3. 剑桥真题：诊断和迁移

真题的作用有三个：

- 检验语料库里的能力能否迁移到连续语流；
- 学习题干与录音之间的同义替换；
- 训练考试节奏、注意力和题型操作。

真题不能替代语料库，语料库也不能替代真题。只听写单词会缺少语篇理解，只刷套题又会反复暴露同样的拼写和听音问题。

## 三、核心训练法

## 1. 点式听力法

公开说明中的定义是：播放剑桥真题时不暂停，快速写出名词、形容词、数字、地址、日期等关键信息，而不是全文听写。

训练目的：

- 让注意力集中在雅思常考信息点；
- 加快从声音到书写的反应；
- 避免全文听写造成的时间浪费；
- 训练一边听、一边抓取答案候选词的能力。

操作方法：

1. 选一个 Part，先不看原文。
2. 从头播放，不暂停。
3. 听到实义名词、关键形容词、数字、日期、地址时快速记录。
4. 播放结束后对照原文，只标出漏掉或误听的“信息点”。
5. 重新播放一次，仍然不暂停，观察捕捉率是否提高。

错误做法：把每个冠词、介词和完整句子都写下来。那会把点式听力变成低效全文听写。

## 2. 复数听写法

复数听写专门训练名词单复数辨音。公开说明指出，雅思听力 40 题中常会有若干题涉及名词复数，`computer` 与 `computers` 在填空评分中不是同一个答案。

训练重点：

- /s/、/z/、/ɪz/ 三类复数尾音；
- 词尾辅音很弱时的辨认；
- `-s` 与后一个词连读时的辨认；
- 题干语法对单复数的约束；
- 特殊名词在特定语境中的复数形式。

判断顺序：

1. 先听声音是否有复数尾音；
2. 再看题干是否需要可数名词复数；
3. 最后用上下文数量词验证；
4. 不能只凭“意思上好像一个”擅自改成单数。

## 3. 魔鬼跟读法

其核心不是普通朗读，而是尽量紧贴原音的节奏、重音、连读和停顿进行模仿。听不清的声音，如果自己从未正确发出过，往往也很难稳定识别。

建议流程：

1. 选 20—40 秒音频，先盲听一次。
2. 看原文解决生词和句意。
3. 逐句模仿，先慢后正常速度。
4. 进行影子跟读：原音开始后延迟约半拍跟上。
5. 录下自己的声音，与原音比较重音、弱读和尾音。
6. 脱离文本再听，确认原来模糊的部分是否变清楚。

它适合解决连读、吞音和口音问题，不适合拿几分钟的长段落一次硬跟。

## 4. 点精训练

“点精”可以理解为把精听限制在真正导致失分的点上：答案句、转折句、定位丢失处和连续弱读处。它与点式听力配合使用。

每个错题只精听以下范围：

- 答案出现前一句；
- 答案句；
- 答案出现后一句或改口句。

每个片段必须回答：

- 我为什么没有定位到？
- 题干哪个词被替换了？
- 干扰信息怎样被否定或修改？
- 我漏的是声音、词义、拼写还是逻辑？

## 5. 横向测试与纵向测试

公开检索资料对两者的共同解释是：横向材料中的单词关联性较强，纵向材料会打散关联，难度更高。语料库音频也分别提供横向、纵向测试版本。

- **横向测试**：适合初次建立同一主题、同一词类的听音反射。
- **纵向测试**：词与词之间缺少上下文关联，更接近纯听音识别；适合已经达到约 7 分、希望继续减少细节错误的人。

顺序建议：先横向达到 90%—95%，再进入纵向；不要基础正确率很低时直接追求最难版本。

## 五、填空题的核心逻辑

### 1. 字数要求是最高规则

先圈出：

- `ONE WORD ONLY`
- `NO MORE THAN TWO WORDS`
- `ONE WORD AND/OR A NUMBER`

答案意思正确但超过字数，仍然不得分。

### 2. 预判答案，而不是等待答案

预判包括：

- 词性：名词、形容词、数字还是专有名词；
- 单复数；
- 内容类别：时间、地点、费用、材料、原因、优点等；
- 可能的语法形式。

课程中反复强调填空答案高度集中于名词和形容词。实际考试仍可能出现其他形式，所以应把它当作高概率原则，不当作绝对规则。

### 3. 定位词和考点词要分开

- **定位词**：专有名词、数字、标题、核心名词，通常较稳定，用来确认讲到哪一题。
- **考点词**：空格前后的动词、形容词、评价词，常被同义替换或改变语序。

若题干写 `make`，录音可能说 `create`；题干写 `good`，录音可能说 `excellent` 或换成评价句。死等原词会错过答案。

### 4. 所听即所得，但必须结合语法验证

尤其是：

- 单复数；
- 金额小数；
- 日期与年份；
- 名字和地址拼写；
- 连字符和合成词。

## 六、选择题的核心逻辑

选择题不是听到选项原词就选。常见结构是：

```text
先提到 A → 否定／修正 A → 比较 B → 最终确认 C
```

必须重点听：

- `but`, `however`, `actually`, `in fact`
- `although`, `even though`
- `rather than`, `instead of`
- `the problem/trouble is ...`
- `I thought/expected ..., but ...`
- `many people think ..., yet ...`

正确答案通常对应说话人的最终态度、共同结论或题干指定人物的观点，而不是第一个出现的信息。

## 七、地图题的核心逻辑

地图题开始前必须完成四件事：

1. 找入口或起点；
2. 标明北、南、东、西；
3. 看清题号顺序和可选字母；
4. 圈出稳定参照物，如入口、停车场、湖、道路、桥、接待处。

听音时不要在脑中旋转整张地图。每一步只处理“从当前点到下一点”的相对方向。

## 八、错误诊断模型

每一道错题只选择一个首要原因：

| 代码 | 错因 | 修复方法 |
|---|---|---|
| A | 单词不认识 | 查义并加入词表 |
| B | 认识但听不出 | 听音、跟读、倍速复测 |
| C | 听出但拼错 | 手写 3—5 次，隔日听写 |
| D | 单复数／格式 | 做专项复数、数字、日期训练 |
| E | 没读懂题 | 重做词性和内容预判 |
| F | 同义替换没认出 | 记录“题干词 → 录音词” |
| G | 被干扰项骗 | 标记否定、转折和最终结论 |
| H | 跟丢题号／走神 | 缩短训练段落，练定位恢复 |
| I | 地图方向错 | 重画路线，只复听方向句 |

一周后统计数量最多的两类错误，它们就是下一周训练重点。

## 九、合理看待这套方法

语料库非常擅长改善听音词汇、拼写、复数和信息反应速度，但它不是所有听力问题的唯一答案。若学习者已经能稳定听写答案词，却仍在 Part 3 观点题或 Part 4 语篇理解中大量失分，就需要增加：

- 题干与录音同义替换整理；
- 逻辑关系和说话人态度训练；
- 短段落精听与复述；
- 正常考试速度的整套练习。

最有效的组合不是“只刷语料库”或“只做真题”，而是：

> 语料库修基本功，题型课修操作，真题修迁移，模考修节奏。
