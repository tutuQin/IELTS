# 你的当前阶段建议怎么练？

结合你正在练王陆语料库：

每天额外10分钟：

### 第1周：

专门练：

数字 + 日期 + 星期 + 月份

方法：

听写：

- 20个数字
    
- 10个日期
    
- 10个电话号码
    

目标：

听到：

August

Wednesday

twenty-third

立即写出来。

因为这些属于雅思听力最容易拿分的基础分。

你现在王陆第一遍大量错，不要只补高级词汇，这些基础元素（数字、日期、拼写）反而是最容易快速提升正确率的部分。
这些内容看起来简单，但是雅思听力7分里面，Section 1如果稳定拿到**9-10/10**，会给后面的Section 3、4留下大量容错空间。你现在练王陆语料库时，可以把这些基础内容作为每天10分钟热身。
