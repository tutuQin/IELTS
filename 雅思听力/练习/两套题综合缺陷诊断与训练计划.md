## 二、五大核心缺陷逐项诊断

### 🔴 缺陷一：同义改写失敏（13题·最高频）

**两套题错例清单：**

| 套题 | 题号 | 题干词 | 录音原文 |
| :--- | :--- | :--- | :--- |
| T1 | Q12 | most | the majority of |
| T1 | Q13 | each day | every day |
| T1 | Q30 | cope with | deal with |
| T1 | Q39 | never | avoid |
| T1 | Q40 | aim | should |
| T1 | Q26 | (未识别) | 改写句 |
| T2 | Q22 | main purpose/equipment | role / clothing+gear（上下义）|
| T2 | Q30 | no nuclear | prohibit |
| T2 | Q35 | most successful | more than（比较级→最高级）|
| T2 | Q38 | bigger area | larger relevant field |
| T2 | Q32 | strategies | tactics |
| T2 | Q23 | show what X is like | recreate the atmosphere |

**根因：** 大脑停留在题干字面原词，一旦录音换词就丢失定位。

**训练方案：**
1. **每套题做完必做的"改写对归库"动作**：打开同义替换积累本，把本套题所有 `题干词 → 录音词` 对填进去
2. **每周一次"改写闪卡"复习**：左手遮右栏，看题干词→出声说录音词，3秒内说不出来的打★重点背
3. **六大改写范式精练**（每天认一组）：
   - 同义词（cope with=deal with）
   - 词性变化（confident→confidence）
   - 上下义（clothing/gear→equipment）
   - 比较级→最高级（more than→most successful）
   - 解释型（recreate atmosphere→show what it's like）
   - 否定改写（prohibit→no/not allowed）

### 🔴 缺陷二：T3 原词陷阱 + T2 转折信号词（共18题影响）

**两套题错例：**

| 套题 | 题号 | 陷阱词（原词出现）| 真正答案位置 |
| :--- | :--- | :--- | :--- |
| T1 | Q16 | rent/tent | 转折后改写版 |
| T1 | Q18 | found | 转折后改写版 |
| T2 | Q21 | Antarctic treaty / climate | *actually* 后 |
| T2 | Q22 | clothing / expedition（举例词）| *for example* 后的总结 |
| T2 | Q25 | 北极相关词（原词）| *dome shaped* 描述南极段 |
| T2 | Q26 | Africa | *because* 后 geological evidence |
| T2 | Q34 | high level（触发C）| *also* 后补充信息 |

**铁律（背熟）：**

```
选择题原词 ≠ 答案
原词出现 80% = 陷阱
转折后（but/however/actually/in fact）= 真正结论
举例后（for example/such as）= 例子是信号，总结才是答案
```

**训练方案：**
1. **"手不落笔法"**：听到选项原词时，拇指放在选项字母旁但不勾，继续听后半句，有转折才落笔
2. **每次做完选择题必做的"陷阱标注"**：在 Audioscript 上，用红笔划出所有出现了但是陷阱的原词，用绿笔圈出真正答案句，统计自己被骗了几次
3. **信号词条件反射清单**（听到→立刻触发动作）：

| 信号词 | 触发动作 |
| :--- | :--- |
| *actually / in fact / but / however* | 前面选项划掉，锁定后面 |
| *for example / such as* | 听例子判断上位总结词 |
| *also / and / as well as* | 继续听，不要提前收割 |
| *this means that / which means* | 笔尖警觉，答案马上来 |
| *sorry / no / I mean / wait* | 前面作废，写修正后的 |

### 🔴 缺陷三：连环卡顿雪崩（两套题损失 9 题）

**雪崩清单：**

| 套题 | 雪崩起点 | 波及题目 | 诱因 |
| :--- | :--- | :--- | :--- |
| T1 | Q22 | Q22→Q23（2题崩） | 节奏脱节 |
| T1 | Q35 | Q35→Q36（2题崩） | Q34写完时Q35已过 |
| T1 | Q37 | Q37→Q38（2题崩） | Q37纠结词性 |
| T2 | Q9 | Q9→Q10（2题崩） | Q9词音错误心态乱 |
| T2 | Q21 | Q21→Q22→Q23（3题崩）| 陷入陷阱后定位全失 |

**根因：** 某题没答出来时，**大脑停留在上一题**，没有强制跳题，导致后续题连续丢分。

**解决动作（笔尖跟号法）：**

```
规则：笔尖永远落在"当前正在播放的题号"上

做题时：
  某题没听到 → 立刻划一横 → 笔尖强制移到下一题
  绝对不允许：因为上一题没写完而停留导致下一题也没听

每次复盘时：
  统计雪崩损失了几题 → 记录在复盘表"雪崩损失"一栏
  目标：下一套题雪崩损失 ≤ 1题
```

| T2 | Q39 | creation ← correction | *-rec-* vs *-ea-* 元音 |

**专项训练资料与方法：**

#### A. 数字专项（覆盖 T1-Q10、T2-Q1、T2-Q27）

| 训练内容 | 方法 | 时间 |
| :--- | :--- | :--- |
| 门牌号 = 数字+街道名 | 听到数字划横线占位，耳朵跟住街道名，最后回填数字 | 每次做题时执行 |

| 年代辨别 eighteen/nineteen | 专项对比跟读 1800s vs 1900s，注意 /eɪt/ 起音 | 每天3分钟 |

#### B. 辅音群专项（覆盖 T2-Q9）

每天10分钟 Minimal Pairs 精听：

| 对比组 | 词A | 词B | 辨别点 |
| :--- | :--- | :--- | :--- |
| 辅音群起音 | flag /flæɡ/ | lag /læɡ/ | fl- vs l- |
| 辅音群起音 | street /striːt/ | treat /triːt/ | str- vs tr- |
| 辅音群起音 | black /blæk/ | lack /læk/ | bl- vs l- |
| 辅音结尾 | left /left/ | let /let/ | -ft |
| 辅音结尾 | asked /ɑːskt/ | ask /ɑːsk/ | -ed后缀 |
| 近音词 | correction | creation | -rec- vs -ea- |

**资料来源**：Rachel's English / BBC Learning English Minimal Pairs 专项音频（免费）

#### C. 词性词尾专项（覆盖 T2-Q20、T2-Q37）

**万能口诀：**
- `-al / -ical / -ent / -ic / -ful / -ous` → **形容词**
- `-ce / -cy / -tion / -ity / -ness` → **名词**

**预读执行动作**：预读时在每个空格旁边标 **N** 或 **Adj**，听录音时用耳朵验证词尾是否匹配

### 🔴 缺陷五：句意断层（10题·填空题核心病根）

**错例：**
- T1 Q1-Q5 连续5题：只听词不理解句子，盲填定位词（hotel/public transport等）
- T2 Q16：views多义词（景观vs观点）语境判断失败
- T2 Q19：8:30写完后耳朵掉线，漏听every twenty minutes
- T2 Q28：treaty词汇盲区导致整句崩塌

**根因：** 抓词式听力（Word Hunting），听到某个词就落笔，没有听完整句逻辑。

**训练方案：**

1. **空前空后预测**（预读时执行）
   - 空前二、空后二：判断词性+语义范畴
   - 例：空前 `every ___` → 填时间频率词；空前 `views of ___` → 填地点或景色名词

2. **句意还原法**（复盘时执行）
   - 每道错题：把答案词代入原句翻译，确认语法成分
   - 例：*"stop rent... views of [答案]"* → 答案是地点名词，不是动词banking

3. **词汇应急词单**（提前背记高频场景词）

| 场景 | 必背词 |
| :--- | :--- |
| 南极/北极 | treaty条约 / expedition考察队 / dome穹顶 / geological地质的 |
| 医疗健康 | prescription处方 / physiotherapy理疗 / symptoms症状 |
| 学术讲座 | hypothesis假设 / methodology方法论 / evidence证据 |
| 商业管理 | revenue收入 / strategy策略 / efficient高效的 |
| 地址填空 | Road/Street/Avenue/Crescent/Terrace/Court/Drive/Lane |
