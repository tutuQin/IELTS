### 2. 致命缺陷二：评价句与邻词诱捕（Q3: much → March，Q6: hurry）

- **Q3 的双重错误**：
  $$\text{It wouldn't be } \underbrace{\textbf{much}}_{\text{评价：量不大}} \text{, } \underbrace{\text{just my } \textbf{shirts}}_{\text{答案}} \text{ for work that week.}$$
  ① /ʌ/ 与 /ɑː/ 元音长度没分辨；② 把评价句里的词当答案，而**答案在 just + 名词**。
- **Q6 的结构陷阱**：
  $$\text{a plumber } \underbrace{\text{in a } \textbf{hurry}}_{\text{邻词诱捕}} \longrightarrow \textbf{And the same thing} \text{ if you need an } \underbrace{\textbf{electrician}}_{\text{答案}}$$
  第二句是**省略句**（省掉谓语），音量与语调都像"顺带一提"，因此极易被判为废话跳过。
- **破解军规**：
  1. 评价句（*It wouldn't be much / not too bad / that's fine*）一律**不算答案**，往后挪半步找 just / only + 名词；
  2. **the same thing / likewise / so is** = 并列新答案的红色警报，必须停笔等名词。

### 3. 致命缺陷三：答案前置的倒装结构（Q7: dust）

```text
录音:  ...by capturing up to 99% of all the DUST in the air.
                                              ↑ 答案在这里（第 1 句）
       So if you're troubled by ALLERGIES, this can make a big difference.
                                ↑ 题干关键词在这里（第 2 句，晚 4 秒）
```

- **为什么必然踩坑**：人的注意力默认"盯住题干关键词等它出现"，而命题者把关键词放到**答案之后**，于是你等到关键词时，答案早已过去，只能抓句尾的 difference。
- **破解铁律 —— "关键词迟到，回头补名词"**：
  - 若题干关键词（allergies）在录音里**迟迟不出现**，说明答案**已经在前面说过**；
  - 立即回头把刚才那句里的**核心名词**（dust）补上；
  - 常见信号：**So / That's why / This means** 之后才是"解释/结论"，答案在这些词**之前**。
